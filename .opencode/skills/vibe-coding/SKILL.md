# Vibe Coding — 창의적인 봇 만들기

코드를 몰라도 괜찮아요. 아이디어만 있으면 됩니다.

## 마인드셋

- **완벽보다 완성** — 일단 만들어보고 고쳐나가요
- **작게 시작** — "안녕"이라고 답장하는 봇부터
- **실수는 학습** — 에러는 나쁜 게 아니에요, 배우는 과정이에요
- **질문 환영** — 모르는 게 있으면 언제든 물어보세요

## 봇 아이디어 발전시키기

사용자가 "봇을 만들고 싶어요"라고 하면, 이렇게 이끌어주세요:

1. **봇 이름 정하기** — 어떤 이름을 붙이고 싶나요?
2. **하는 일 정하기** — 이 봇이 무슨 일을 하면 좋을까요?
   - 특정 키워드에 반응? (예: "날씨" → 오늘 날씨 알려줘)
   - 명령어로 동작? (예: `!help`, `!번역`)
   - 모든 메시지에 답장?
3. **플로우 vs 코드** — 비주얼로 만들래요, 아니면 직접 코드를 써볼래요?
   - 플로우 추천: 처음이거나 간단한 로직
   - 코드 추천: 더 복잡하거나 세밀한 제어

## 난이도별 추천 프로젝트

### 입문 (플로우로 충분)
- "안녕"이라고 치면 "안녕하세요!" 답장
- `!help` 명령어로 도움말 출력
- 특정 단어가 포함되면 토스트 띄우기

### 중급 (간단한 코드)
- 조건에 따라 다른 답장
- 여러 명령어 지원
- 메시지 내용 가공해서 응답

### 고급 (Python/Node.js)
- 외부 API 호출
- 파일/데이터 저장
- 복잡한 조건 분기

## 권장하는 접근법

1. **봇의 성격을 정해요** — 친근한 말투? 공손한 말투? 재미있는 말투?
2. **한 가지 동작부터** — 모든 걸 한 번에 하려고 하지 마세요
3. **테스트는 카톡으로** — 봇을 켜고 카톡에서 직접 메시지를 보내보세요
4. **로그 확인** — 봇이 어떻게 동작하는지 로그 탭에서 볼 수 있어요
